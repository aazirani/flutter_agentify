# Security Policy

## Supported versions

There are no versions. Fixes go into `main`; bring them into a project with `dart tool/upgrade.dart`.

## Reporting

Report a vulnerability through the private form at
https://github.com/aazirani/flutter_agentify/security/advisories/new.
Do not open a public issue.

## What counts

- A way past the approval gate.
- An API key reaching a model, a log or anywhere other than the platform's secure storage.
- A change the assistant makes without a receipt.

## What to expect

You get an answer within seven days. Fixes land on `main` and are noted in the changelog.
