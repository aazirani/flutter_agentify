# flutter_agentify_core

Pure Dart: actions and their registry, app context, the agent loop with approval, model providers, storage interfaces, the doctor, the action CLI and docs search.

## Use

```dart
import 'package:flutter_agentify_core/flutter_agentify_core.dart';
```

The guides are in [`doc/`](doc/). Search them with `dart run flutter_agentify_core:docs --query "<words>"`.

This package is used by path and is not on pub.dev.
