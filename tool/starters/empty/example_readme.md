# The item example

This folder holds the item example from the Flutter Agentify template: a list of items with its actions, database table, screen and tests.

- It is reference code. Nothing here is compiled or tested.
- The skills point here when they show how something is built.
- Each file sits at the path it had in the template. `.agents/example/lib/domain/actions/items_actions.dart` was `lib/domain/actions/items_actions.dart` in the app.
- An upgrade replaces this folder. Do not edit it; copy what you need into the app instead.
